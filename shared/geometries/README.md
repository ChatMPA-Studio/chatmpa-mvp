# shared/geometries

Spatial reference files used across skills. Skills never read these directly —
they receive an `sf` object via `get_amp_geometry()` or `get_lme_geometry()` from
`shared/spatial_join/spatial_join.R`.

## For engineers deploying the platform

**No setup needed.** All geometry files are committed to this repo:

| File | Contents | Source |
|------|----------|--------|
| `amp_geometry_lookup.csv` | Maps CONANP AMP name → geometry source (`WDPA` or `CONANP_pending_review`) and WDPA name for matching | Generated by `setup_amp_geometries.R` |
| `wdpa_mex_amps.gpkg` | Polygons for the 32 AMPs with `geometry_source = WDPA` (WGS84, from WDPA MEX dataset) | Downloaded from WDPA via `wdpar`, saved once |
| `conanp_overrides.gpkg` | Polygons for AMPs with `geometry_source = CONANP_pending_review` (Jaccard < 0.95 vs WDPA) | CONANP official shapefile |
| `lme/` | Large Marine Ecosystem polygons (cached from Marine Regions API on first use) | `mregions2` |

`get_amp_geometry("Cabo Pulmo")` reads from `wdpa_mex_amps.gpkg` or
`conanp_overrides.gpkg` — **no internet connection required at runtime**.

## Jaccard threshold

AMPs with Jaccard ≥ 0.95 against WDPA use the WDPA polygon (`wdpa_mex_amps.gpkg`).
AMPs with Jaccard < 0.95 or no WDPA match use the CONANP polygon
(`conanp_overrides.gpkg`) and are flagged `geometry_source = CONANP_pending_review`.
Review flagged AMPs when CONANP publishes updated geometries.

## How to regenerate (only needed if WDPA updates or new AMPs are added)

### 1. Regenerate `wdpa_mex_amps.gpkg`

```r
library(sf); library(dplyr); library(readr); library(wdpar)

GEOM_DIR  <- "shared/geometries"   # relative to repo root
cache_dir <- file.path(GEOM_DIR, "wdpa_cache")
dir.create(cache_dir, showWarnings = FALSE)

wdpa_mex <- wdpa_fetch("MEX", wait = TRUE, download_dir = cache_dir)

lookup     <- read_csv(file.path(GEOM_DIR, "amp_geometry_lookup.csv"))
wdpa_names <- lookup |> filter(geometry_source == "WDPA") |> pull(wdpa_nombre)

matched <- wdpa_mex |>
  filter(NAME %in% wdpa_names | NAME_ENG %in% wdpa_names) |>
  st_transform(4326) |>
  select(NAME, NAME_ENG, REP_M_AREA)

st_write(matched, file.path(GEOM_DIR, "wdpa_mex_amps.gpkg"), delete_dsn = TRUE)
```

### 2. Regenerate `amp_geometry_lookup.csv` and `conanp_overrides.gpkg`

Run `setup_amp_geometries.R`. Requires:
- `comparar_amp_wdpa_conanp.csv` — Jaccard scores computed by Carol (ask her for the file)
- `232-ANP_ITRF08_19162026.zip` — CONANP official shapefile (download from CONANP portal)

Edit the paths at the top of `setup_amp_geometries.R` before running.
