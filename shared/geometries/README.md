# shared/geometries

Spatial reference files used across skills. Skills never read these directly —
they receive an `sf` object via `get_amp_geometry()` or `get_lme_geometry()` from
`shared/spatial_join.R`.

## Files

| File | Contents | Source | Updated |
|------|----------|--------|---------|
| `amp_geometry_lookup.csv` | Maps AMP name → geometry source (WDPA or CONANP_override) + WDPA name for API | Generated by `setup_amp_geometries.R` | 2026-07-17 |
| `conanp_overrides.gpkg` | AMP polygons from CONANP shapefile where Jaccard < 0.95 vs WDPA | CONANP official shapefile | 2026-07-17 |
| `lme/` | Large Marine Ecosystem polygons (cached from Marine Regions API) | mregions2 | pending |

## Jaccard threshold

AMPs with Jaccard < 0.95 against WDPA use the CONANP polygon (stored in
`conanp_overrides.gpkg`) and are flagged `geometry_source = "CONANP_pending_review"`.
All others use WDPA fetched via `wdpar`. Review flagged AMPs when CONANP
publishes updated geometries.
